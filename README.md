# Watch Store Inventory Management

## 📌 Project Overview

The Watch Store Inventory Management System is a web-based application designed to manage watch products, stock levels, and inventory operations efficiently.
It provides an easy interface for managing product details and maintaining records in a structured way.

---

## 🚀 Features

* Add new watch products
* Update product details
* Delete products from inventory
* View available stock
* Simple and user-friendly interface

---

## 🛠 Technologies Used

* Python (Flask Framework)
* SQLite Database *(not included in repository)*
* HTML, CSS

---

## 📂 Project Structure

* `app.py` → Main application file
* `database/` → Contains database schema
* `templates/` → HTML pages
* `static/` → CSS, JavaScript, and images

---

## ⚙️ Installation

1. Clone the repository:
   git clone https://github.com/your-username/Watch-Store-Inventory-Management.git

2. Navigate to project folder:
   cd Watch-Store-Inventory-Management

3. Install dependencies:
   pip install flask

4. Run the application:
   python app.py

5. Open browser:
   http://127.0.0.1:5000/

---

## 🗄 Database

SQLite is used as the database.
The database file is **not included** in this repository for security reasons.
You can create your own database using the schema provided in the project.

---

## ❗ Note

* Ensure Python is installed before running the project
* Database file must be created manually
* Update database path in `app.py` if required
